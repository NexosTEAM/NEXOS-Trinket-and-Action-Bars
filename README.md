# NEXOS Trinket and Action Bars

A lightweight, customizable World of Warcraft addon for managing equipped trinkets and creating personalized item action bars.

**Version:** 1.0.0  
**Developer:** NexosTEAM  
**Supported Clients:** Forever and Midnight

## Features

### Trinket Management
- Manage both equipped trinket slots (13 and 14).
- Use equipped trinkets directly from the interface.
- Select replacement trinkets from your inventory.
- Queue equipment changes during combat for automatic swapping afterward.
- Display trinket cooldown timers.
- Highlight selected and pending trinkets.

### Custom Item Action Bar
- 16 customizable item slots.
- Horizontal (8×2) and vertical (2×8) layouts.
- Assign inventory items to individual slots.
- Left-click to use assigned items.
- Shift-click to rearrange or swap item positions.
- Right-click to open the item selection menu.
- Display item quantities, including zero.
- Show item tooltips and inventory counts.
- Automatically refresh icons and cooldown displays.

### Interface Customization
- Independently movable trinket and item bars.
- Horizontal and vertical orientation options.
- Minimap controls.
- Independent visibility settings.
- Compact interface.
- Persistent settings across normal addon updates.

## Installation

1. Download the latest release.
2. Extract the addon folder into your World of Warcraft `Interface/AddOns` directory.
3. Ensure the folder is named `NEXOS_Trinket_Action_Bars`.
4. Enable the addon from the game's AddOns menu.

## Commands

- `/nextrinket` — Trinket controls.
- `/nexitems` — Item bar controls.
